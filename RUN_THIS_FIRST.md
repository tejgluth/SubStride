# RUN_THIS_FIRST.md

1. Unzip this folder.
2. Open terminal inside the `SubStride` folder.
3. Start with `PROMPT_1_CODEX_BACKEND_FIRMWARE_ANALYTICS.md`.
4. Paste that entire file into Codex and let it build the foundation.
5. Test what Codex creates.
6. Then run `PROMPT_2_CLAUDE_UI_UX.md` inside the same folder with Claude Code.
7. After Prompt 2, add real API keys/integrations if needed:
   - OpenAI API key for AI interpretations
   - Supabase keys later when you decide to enable cloud sync

Do not run Prompt 2 first. Claude Code should polish an already-working app, not invent the backend.
